# EAC design world v0.4.1

发布日期：2026-10-23。本版为修复版，不含新功能，不删除或重命名任何上游文件。

## 本版定位

v0.4.0 之后的一次集中审查修复，共 21 项，覆盖模板读取边界、渲染导出收容、数据目录并发、媒体时长与导出边界、转录错误语义、本地安装令牌、模板资产补回。全部变更的逐条清单见 [CHANGELOG](../CHANGELOG.md)。

## 主要修复

- **路径与渲染收容**：`template_read`、`library_read`、`render-template` 的入口统一定义在明确根目录内；符号链接按 `realpath` 判定；导出页沙箱化并切断外联。
- **数据目录并发**：同一数据目录只允许一个运行中的实例，第二个实例被拒绝而不是静默覆盖；锁写入改为原子发布，陈旧锁可被接管。
- **媒体时长与边界**：截取与导出按片段实际读取的那条流计时；清点末包 PTS 确定结束边界；ffmpeg 9 的选项变化按帮助文本自动适配。
- **转录**：未配置模型时明确报错，不再回落到编造路径；语言等纯参数校验先于环境探测。
- **本地安装**：未签名安装改为一次性令牌，安装失败也消耗令牌，重试需重新获取。
- **模板资产**：补回被 `.gitignore` 误伤的 900 个 OpenDesign 设计体系模板。

## 升级须知

- 升级后首次启动若提示数据目录被占用，说明旧实例仍在运行。停止旧实例后重试即可；本版不会自动抢占或改写数据目录。
- 无数据库迁移、无配置项改名、无 CLI 参数变化。

## 验证状态

- 本机（Windows 11，Node.js 24.16，ffmpeg 9.0.2）执行完整测试套件：290 项，279 通过、11 跳过、0 失败。
- 11 项跳过均为环境条件：4 项缺本地 Whisper 模型，4 项缺 cordis 内核，1 项缺 dsh-client-modules（两者都是可选宿主依赖），2 项为上游既有的资产/平台条件跳过。缺模型与缺可选库的用例会显式跳过并给出原因，不再是失败。
- 自动化：`.github/workflows/ci.yml` 在 Windows runner 上执行 `npm ci`、`npm run build`、`npm test`，并预先安装 ffmpeg；首次运行结果见仓库 Actions 页。

## 已知限制

- 桌面录制、本地语音与 SAPI 仍只在 Windows 上实现；其他平台未实现（与上游 issue #2 一致）。
- 转录需自备本地 faster-whisper 模型目录，运行时不会下载。
